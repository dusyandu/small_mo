# 05-商品价格监控

电商商品价格监控 + 微信推送 + 定时任务调度。

## 文件清单

| 文件 | 说明 | 关键技术 |
|------|------|----------|
| `监控京东商品价格.py` | 京东商品价格监控 | 接口抓取 + 阈值告警 |
| `监控淘宝商品价格.py` | 淘宝/天猫价格监控 | DrissionPage + Server酱微信推送 |
| `自动结束定时任务/jd_spider.py` | 京东定时采集 | 定时调度 |
| `自动结束定时任务/tb_spider.py` | 淘宝定时采集 | 定时调度 |
| `自动结束定时任务/timing.py` | 定时任务主控 | 任务编排 + 超时自动收尾 |

## 技术要点

- **阈值告警**：商品价格低于 `ideal_price` 时触发推送。
- **Server酱推送**：通过 `sct.ftqq.com` 发送微信通知。
- **定时任务收尾**：`timing.py` 管理任务生命周期，超时自动结束避免僵尸进程。

# 03-浏览器自动化与社交平台

基于 [DrissionPage](https://github.com/g1879/DrissionPage) 的浏览器自动化数据采集，针对动态渲染与需要登录态的社交平台。

## 文件清单

| 文件 | 目标平台 | 说明 |
|------|----------|------|
| `小红书数据提取.py` | 小红书 | 笔记数据提取 |
| `猪八戒数据获取.py` | 猪八戒网 | 服务/任务数据采集 |
| `猿急送数据获取.py` | 猿急送 | 技术服务数据采集 |

## 技术要点

- **DrissionPage**：兼顾 requests 的轻量与 Selenium 的浏览器驱动能力，支持 CDP 协议直接操控。
- **动态渲染应对**：浏览器模式下渲染 JS，获取接口请求拿不到的异步内容。
- **登录态处理**：复用浏览器已登录会话，避免重复鉴权。

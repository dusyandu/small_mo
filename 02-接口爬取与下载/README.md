# 02-接口爬取与下载

基于 HTTP 接口的数据抓取与资源下载。

## 文件清单

| 文件 | 说明 | 关键技术 |
|------|------|----------|
| `壁纸下载/批量爬取壁纸.py` | 壁纸批量下载 | 接口请求 + 文件流写入 |
| `小说下载/小说下载.py` | 小说章节抓取 | 章节列表遍历 + 文本拼接 |
| `视频下载/b站视频下载.py` | B站视频下载 | 接口解析 + moviepy 合并 |
| `音乐下载/音乐下载.py` | 音乐资源下载 | 接口抓取 + 音频下载 |

> ⚠️ `b站视频下载.py` 中的 cookie 已脱敏为占位符，运行前需替换为你自己的 B站 cookie。

# 07-反爬避坑实战

渐进式反爬实战 demo，由浅入深覆盖常见反爬场景。

## 文件清单

| 文件 | 主题 | 学习要点 |
|------|------|----------|
| `demo1贝壳二手房数据获取.py` | 静态页解析 | requests + HTML 解析入门 |
| `demo2页面滚动.py` | 滚动加载 | 动态渲染 + 滚动触发的异步内容 |
| `demo3验证码识别.py` | 验证码 | 验证码识别实战 |
| `demo4多页数据获取.py` | 多页翻页 | 翻页规律 + 鉴权 + 多页连续采集 |

## 学习路径

demo1 → demo4 是一条由易到难的爬虫学习路线，建议按序阅读。

> `captcha_solver.py`（见 `01-反爬与验证码破解`）正是在 demo3/demo4 基础上演进的完整验证码破解模块，保留了对 demo4 调用方式的向后兼容。
